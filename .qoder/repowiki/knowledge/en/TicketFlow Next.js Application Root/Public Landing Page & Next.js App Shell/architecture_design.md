Three Next.js special files form the public surface:
- `pages/_document.js` customizes the HTML `<head>` to preload Inter, Plus Jakarta Sans, and Manrope fonts from Google Fonts.
- `pages/_app.js` is the root React component that imports the global stylesheet (`styles/global.css`), wraps every page in a shared `Layout` (with per-page `getLayout` override) and a `ToastProvider` for global toast notifications.
- `pages/index.js` is the home page: a server-side rendered React component that fetches published events via Supabase (`getServerSideProps`) and falls back to an inline `DEMO_EVENTS` array when none are available. It composes UI through shared components from `components/Layout` and `components/ui` (Badge, Button, Card, Progress, CountdownTimer). Client-side state drives search filtering, category tabs, favorites (persisted in `localStorage` under key `tf-favs`), share-to-clipboard, FAQ accordion, and newsletter subscription. Data helpers (`detectCategory`, `minPrice`, `totalSold`, `percentSold`, `daysUntil`) compute derived values used across the hero, featured section, and event grid.
