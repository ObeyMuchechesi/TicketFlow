The root declares the Next.js 15 project via package.json scripts (dev/build/start) and next.config.js, which enables React StrictMode and whitelists Unsplash and Supabase image domains. vercel.json configures the deployment framework, build/dev commands, region (iad1), and security headers for all /api routes. The pages_public child provides the App Router entry points and UI, while the lib child supplies singleton clients for Supabase and Stripe plus hashing/session helpers consumed by both server and client code. All children share the same Node/Next runtime and are bundled together as one Vercel-deployable unit.
