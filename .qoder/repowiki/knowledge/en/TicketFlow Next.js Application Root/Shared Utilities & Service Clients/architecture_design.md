Three independent utility modules with no internal dependencies on each other except `auth.js` importing `getServiceClient` from `supabase.js`. `supabase.js` exports both a public anonymous client (`supabase`) and an admin service-role client factory (`getServiceClient`). `stripe.js` exposes a single configured Stripe instance. `auth.js` wraps bcrypt for password hashing and implements a simple base64-encoded JSON session cookie scheme (`tf_session`) with role-based access control via `requireRole`. Each module is a flat ES module exporting named functions or constants, intended to be imported by API routes and server components.
